# 미드나잇맨즈 Telegram 봇

이 봇은 개인 대화에서 `/start` 명령으로 미드나잇맨즈 메뉴를 제공합니다. 그룹 명령,
그룹에 새로 입장한 멤버에게는 이미지와 함께 사용자 정보 및 이용 규정을 안내합니다.
`/dbinfo`, `/chatid`, 그룹 초이스톡 자동 답장은 제공하지 않습니다.

`/testt` 명령을 입력하면 굵게, 기울임, 밑줄, 취소선, 스포일러, 코드,
인용문, 링크, 텍스트 멘션, 커스텀 이모지 등 Telegram Bot API가 지원하는
텍스트 서식을 한 메시지에서 확인할 수 있습니다.

## 설정

프로젝트 루트의 `.env`에 다음 값을 설정합니다.

- `BOT_TOKEN`: BotFather에서 발급받은 Telegram 봇 토큰
- `TELEGRAM_ANNOUNCEMENT_CHAT_ID`: 미드나잇맨즈 공지방의 숫자 채팅 ID
- `TELEGRAM_COMMUNITY_CHAT_ID`: 환영 메시지를 사용할 미드나잇맨즈 소통방의 숫자 채팅 ID
- `TELEGRAM_WELCOME_PHOTO_PATH`: 그룹 환영 이미지 경로(선택 사항)
- `TELEGRAM_MEMBER_STORE_PATH`: 그룹 회원 정보 JSON 저장 경로(선택 사항,
  기본값 `data/group-members.json`)
- `TELEGRAM_ADS_CONFIG_PATH`: 반복 광고 JSON 경로(선택 사항, 기본값 `data/ads.json`)
- `MNMS_MYSQL_*`: 개인 메뉴의 제휴업체 정보를 조회할 데이터베이스 접속 정보
- `CHATBOT_MYSQL_*`: 개인 메뉴의 LIVE 정보를 조회할 데이터베이스 접속 정보
- `WEBSITE_URL`, `RBTI_URL`, `WIKI_URL`, `PARTNERS_URL`, `SUPPORT_URL`:
  개인 메뉴 버튼의 이동 주소

```bash
npm install
npm start
```

## 그룹 반복 광고

`data/ads.example.json`을 `data/ads.json`으로 복사한 뒤 대상 그룹 ID,
최초 전송 시각과 반복 간격을 설정합니다. 봇을 대상 그룹의 관리자로 추가하고
메시지 및 사진 전송 권한을 부여해야 합니다. 설정 파일이 없으면 광고 기능만 비활성화되며
나머지 봇 기능은 그대로 실행됩니다.

- `groups`: 전송할 숫자 그룹/슈퍼그룹 ID 배열 (`-100...`)
- `source`: `business_ads`로 설정하면 업체정보와 동일하게 등록이 완료되고 일반 또는 조각
  광고 활성 기간이 남은 프리미엄·플러스 업체만 ID 오름차순으로 한 개씩 순환 전송합니다.
- `startTime`: 시간대가 포함된 ISO 8601 최초 전송 시각(예: `2026-09-07T09:00:00+09:00`)
- `repeatMinutes`: 반복 간격(분). 매시간 전송하려면 `60`을 입력합니다.
- `enabled`: `false`인 광고는 예약하지 않습니다.
- `disableNotification`: `true`이면 알림음 없이 전송합니다.

시작 시각이 이미 지났다면 최초 시각을 기준으로 계산한 다음 반복 시각부터 전송합니다.
설정을 변경한 뒤에는 봇을 재시작해야 새 설정이 반영됩니다. 한 그룹 전송이 실패해도 같은
광고의 다른 그룹 전송 및 이후 반복 예약은 계속 진행되며 결과는 `[ads]` 로그에 기록됩니다.

DB 광고의 사진은 `image_url`, 제목은 `title`, 연락처는 `manager_contact`에서
가져옵니다. `kakao_talk_id`와 `telegram_id`는 값이 있을 때만 표시되며,
텔레그램 ID는 클릭 가능한 `t.me` 링크로 전송됩니다. 각 전송 시점에 DB를
다시 조회하므로 활성 상태 변경과 새 광고 추가는 봇 재시작 없이 반영됩니다. 자동 홍보는
업체정보 목록의 최신 점프 순서를 사용하지 않으므로, 점프로 목록 순서가 바뀌어도 발송
순서는 바뀌지 않습니다.

## 그룹 신규 멤버 환영 메시지

기본 환영 이미지 경로는 프로젝트 루트의 `assets/group-welcome.png`입니다. 해당 경로에
이미지를 넣은 뒤 봇을 그룹 관리자로 추가해 사용합니다. 다른 위치의 이미지를 사용할
경우 `.env`의 `TELEGRAM_WELCOME_PHOTO_PATH`에 절대 경로나 프로젝트 실행 위치 기준
상대 경로를 지정할 수 있습니다.

이미지 파일이 없거나 Telegram이 이미지 전송을 거부하는 경우에도 환영 문구는 텍스트
메시지로 자동 재전송됩니다.

실행 로그에서 `[welcome]` 항목을 확인하면 핸들러 등록 시의 채팅 ID/이미지 파일 상태,
신규 멤버 업데이트 수신 여부, 채팅 ID 불일치로 무시된 이유, 이미지 및 대체 텍스트의
전송 결과를 단계별로 확인할 수 있습니다. Telegram이 `new_chat_members` 서비스 메시지를
보내지 않고 `chat_member` 상태 변경만 보내는 경우에도 `left`/`kicked` 상태에서 실제 멤버
상태로 바뀐 것을 확인해 환영 메시지를 전송합니다. 두 업데이트가 모두 오는 경우에는 같은
사용자에게 환영 메시지가 중복 전송되지 않습니다.

`TELEGRAM_COMMUNITY_CHAT_ID`와 일치하는 그룹 또는 슈퍼그룹에 새 멤버가 입장할
때만 사용자명, 텔레그램 사용자 ID, 고유번호와 한국 시간 기준 입장 일시를 이미지
설명으로 전송합니다. 해당 값이 비어 있거나 다른 그룹에서는 환영 메시지가 작동하지
않습니다.

신규 멤버는 입장 후 10분 동안 해당 그룹에서 URL 또는 텍스트에 연결된 링크를 작성할
수 없습니다. 제한 시간 안에 전송된 링크 메시지나 링크가 포함된 미디어 설명은 자동으로
삭제됩니다. 이를 위해 봇에 그룹 메시지 삭제 권한을 부여해야 합니다.

회원은 그룹 ID와 변하지 않는 텔레그램 고유번호의 조합으로 식별하므로, 탈퇴 후 다시
입장해도 별도 회원으로 중복 생성되지 않고 기존 경고·제재 기록을 그대로 이어서 사용합니다.
사용자명이나 이름이 변경된 경우에는 기존 회원 레코드의 현재 정보만 갱신합니다.

회원의 텔레그램 고유번호, 사용자명, 이름, 언어, 봇 여부, 최초·최근 입장 시각, 가입 횟수,
재입장 이력 및 현재 가입 상태는 데이터베이스 대신 JSON 파일에 영구 저장됩니다. 링크
제한 종료 시각과
향후 경고·뮤트·밴·강퇴 기능에서 사용할 관리 상태도 같은 회원 레코드의 `moderation`에
저장되므로 봇을 재시작해도 유지됩니다. 저장 파일에는 개인정보와 관리 기록이 포함되므로
외부에 공개하지 말고 백업 및 파일 접근 권한을 안전하게 관리해야 합니다.

## 그룹 관리 명령어

소통방의 관리자만 다음 명령어를 사용할 수 있습니다. 저장된 `@아이디` 대신 숫자
텔레그램 고유번호를 입력하거나 대상 사용자의 메시지에 답장하면서 명령어만 보내도 됩니다.
봇에는 사용자 제한 및 차단 권한이 필요합니다. 관리자가 아닌 사용자가 관리 명령어를
입력하면 봇은 아무 메시지도 보내지 않고 무시합니다. 관리자가 `익명으로 남기`를 켜고
그룹 이름으로 명령어를 보내는 경우도 관리자 명령으로 인식합니다.

- `🔊 /뮤트 @아이디`: 대상 사용자의 채팅을 무기한 제한합니다.
- `🔊 /뮤트 @아이디 30`: 대상 사용자의 채팅을 입력한 시간(분) 동안 제한합니다.
- `🔊 /뮤트해제 @아이디`: 대상 사용자의 채팅 제한을 해제합니다.
- `👢 /강퇴 @아이디`: 그룹에서 내보내되 다시 가입할 수 있게 합니다.
- `🚫 /밴 @아이디`: 그룹에서 차단하고 다시 가입하지 못하게 합니다.
- `⚠️ /경고 @아이디`: 대상에게 수동 경고를 부여합니다.
- `✅ /경고초기화 @아이디`: 대상의 누적 경고와 경고 이력을 지우고 0회로 초기화합니다.

일반 회원이 동일하거나 유사한 문구를 3회 연속 전송하거나 15초 동안 메시지를 10개
이상 전송하면 봇이 자동으로 경고합니다. 명령어와 봇·관리자의 메시지는 자동 감지에서
제외합니다. 경고 1회에는 경고 안내, 2회에는 10분 뮤트, 3회부터는 밴이 자동으로
적용되며 수동 경고도 동일한 누적 기준을 사용합니다.

## `/start` 동작

- 그룹이나 채널에서 받은 `/start`에는 응답하지 않습니다.
- 개인 대화에서 `/start`를 받으면 명령보다 앞선 최근 메시지를 최대 100개까지 정리합니다.
- 공지방과 소통방 구독 여부를 확인한 뒤 개인 메뉴를 표시합니다. 구독하지 않은 방이
  있으면 가입 링크와 `구독 완료했어요` 버튼을 표시합니다.
- 개인 메뉴에서는 LIVE, RBTI, 룸빵 용어사전, 제휴업체, 커뮤니티 및 문의 링크를
  이용할 수 있습니다.
- 가입 상태 조회를 위해 봇을 두 방의 관리자로 추가하고 `TELEGRAM_*_CHAT_ID`에는
  `-100...` 형식의 실제 숫자 ID를 설정해야 합니다.

## Telegram 봇 상태 확인

서버의 환경 설정과 두 구독 채팅에서 봇의 관리자 상태는 다음 명령으로 확인할 수
있습니다. 봇 토큰은 출력하지 않습니다.

```bash
npm run telegram:status
```

## 파일 구조

```text
src/
├── bot.js                 # 봇 생성 및 기능 조립
├── config/telegram.js     # 구독 채팅과 메뉴 링크 설정
├── handlers/groupWelcome.js # 그룹 신규 멤버 환영 메시지
├── handlers/menu.js       # /start 및 개인 메뉴 처리
├── services/              # 구독 상태와 개인 메뉴 데이터 조회
└── ui/                    # 개인 안내 문구와 인라인 키보드
```
